# PocketMail logo

Direction 1, "Envelope pocket": a letter sliding into a pocket, on a DSM-style rounded blue tile.

| File | Use |
| --- | --- |
| `pocketmail-icon.svg`, `favicon.svg` | App icon and browser tab (128×128 tile) |
| `pocketmail-icon-{16,32,48,180,192,512}.png` | Raster sizes (180 = Apple touch icon, 192/512 = web manifest) |
| `favicon.ico` | 16/32/48 px for old browsers |
| `pocketmail-mark.svg` | The envelope alone, no tile, for use on light grounds |
| `pocketmail-logo.svg` | Horizontal lockup for light backgrounds |
| `pocketmail-logo-dark.svg` | Horizontal lockup for dark backgrounds |

Colours: blue `#35a0f2` → `#0b6fbf`, white, ink `#1c2733`, muted `#51606f`.
The lockups set the wordmark as live text (Open Sans, falling back to system sans); convert it to outlines before using the file where the font is not installed.
